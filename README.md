# Nova

A browser-style home base that runs in a normal browser tab: themes, tabs, quick links,
notes, tasks, a focus timer, a calculator, a whiteboard, and study sites like Desmos and
GeoGebra shown right inside Nova.

Open it at **https://barillejack-lang.github.io/nova/**

This repo holds only the built page. Your notes and settings stay in your own browser.
